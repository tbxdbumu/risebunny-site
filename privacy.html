Gizlilik Politikası

RiseBunny'nin hangi verileri topladığını, nerede sakladığını ve nasıl silebileceğini açıkça yazdık. Kısa tutmaya çalıştık.

Son güncelleme: 3 Kasım 2026 Sürüm 1.0

1. Kısa özet

RiseBunny bir Discord botudur. Sunucuya eklendiğinde, sana hizmet verebilmek için sınırlı miktarda veri işler. Mesaj metinlerini kalıcı olarak saklamayız, reklam ağı yoktur, veriyi satmayız ve yapay zekâ modeli eğitmek için kullanmayız.

2. Hangi verileri işliyoruz

2.1 Kimlik verileri

  • Discord kullanıcı kimliği (ID) ve sunucu kimliği (ID)
  • Kullanıcı adı — yalnızca kayıt, isim değişikliği ve moderasyon loglarında
  • Sunucu içindeki roller ve kanal kimlikleri (yetki kontrolü için)

2.2 Bot kullanım verileri

  • Seviye sistemi: mesaj sayısı, XP puanı, seviye
  • Ekonomi: bakiye, envanter, en son günlük ödül zamanı
  • Kayıt sistemi: kayıtlı isim, yaş (yalnızca yetkilinin girdiği değer), isim geçmişi
  • Tercihler: dil seçimi, veri işleme onayı
  • Otomasyon ve ayarlar: sunucu yöneticisinin kurduğu kanal, rol ve eşik değerleri

2.3 Mesaj içeriği

Mesaj metinleri kalıcı olarak saklanmaz. İçerik yalnızca şu durumlarda o anlık işlenir:

  • Sunucu yöneticisinin açtığı spam, küfür veya reklam filtresi devrede olduğunda (mesaj silinir, metin saklanmaz)
  • Tanımlı öneyle başlayan bir bot komutu
  • Botu etiketleyerek veya botun mesajına yanıt vererek soru sorduğunda
  • Çekilişe katılım sırasında

Bu işlem bittikten sonra mesaj metni hafızadan düşer. Sunucu yöneticisi filtresini kapatırsa bot mesajları incelemez.

3. Verileri nerede saklıyoruz

Sunucu ayarları ve kullanıcı verileri, botun kendi barındırdığı veritabanında tutulur. Veriler üçüncü taraflara satılmaz, kiralanmaz veya paylaşılmaz. Reklam ağı, izleme pikseli veya satış yoktur.

4. Ne kadar süre saklıyoruz

  • Sunucu ayarları: bot sunucudan çıkarılana kadar
  • Kullanıcı verileri (XP, bakiye, kayıt): silme talebine kadar
  • Geçici cooldown ve benzeri teknik kayıtlar: dakikalar ile birkaç gün
  • Moderasyon logları: sunucu yöneticisinin belirlediği süre

5. Yapay zekâ

Sunucu içindeki yapay zekâ destek asistanı, yalnızca sorduğun soruya hızlı cevap almak için çalışır. Sorunu o an işler ve sunucunun yönetici tarafından girilmiş SSS verisinden yanıt üretir.

Mesajların hiçbir yapay zekâ modelini eğitmek için kullanılmaz, eğitim verisi olarak toplanmaz veya dışarı aktarılmaz. Konuşma geçmişi model eğitimi amacıyla saklanmaz.

6. Onayın

Botu ilk kullandığında bir onay paneli gösterilir. Onay vermezsen bot komutlarını çalıştırmaz ve mesajlarını işlemez. Onay verdiysen, bu politikayı kabul etmiş sayılırsın.

Onayını geri çekmek için r!verisil komutunu kullan veya aşağıdaki destek sunucusundan bizimle iletişime geç.

7. Hakların

Hakkında tuttuğumuz verileri görmek, düzeltmek veya silmek için r!verisil komutunu kullan ya da bize ulaş. Talebin geldiğinde:

  • Verilerini en geç 30 gün içinde sileriz
  • Silinen veriler yedeklerden de temizlenir
  • Daha önce hiçbir veri paylaşılmadığı için geri çekilecek bir paylaşım olmaz

8. Değişiklikler

Bu politikayı güncellersek bu sayfada yayınlarız ve üstteki sürüm numarasını artırırız. Önemli bir değişiklik olduğunda destek sunucusundan duyururuz.

9. İletişim

Gizlilikle ilgili her soru, talep veya şikâyet için:

  • Destek sunucusu: dsc.gg/risebunny

Not: Bu politika, kişisel verilerin işlenmesiyle ilgili genel ilkeleri açıklar. Kesin hukuki tavsiye değildir. Yasal bir uyuşmazlık durumunda kendi ülkenin veri koruma mevzuatı esas alınır.

1. Summary

RiseBunny is a Discord bot. When it is added to your server, it processes a limited amount of data to provide the service. We do not permanently store message text, there is no ad network, we do not sell data and we do not use it to train AI models.

2. Data we process

2.1 Identity data

  • Discord user ID and server (guild) ID
  • Username — only in registration, nickname changes and moderation logs
  • Roles and channel IDs inside the server (for permission checks)

2.2 Usage data

  • Level system: message count, XP, level
  • Economy: balance, inventory, last daily reward time
  • Registration: registered name, age (only the value an admin entered), name history
  • Preferences: language choice, data processing consent
  • Automation and settings: channels, roles and thresholds an admin configured

2.3 Message content

Message text is never stored permanently. Content is processed only in these cases:

  • When a server admin enabled the spam, profanity or invite filter (the message is deleted, text is not stored)
  • When a message starts with the configured command prefix
  • When you ask a question by mentioning the bot or replying to its message
  • When you enter a giveaway

The text is dropped from memory once processing finishes. If the admin turns the filters off, the bot does not inspect messages.

3. Where we store data

Server settings and user data are kept in the bot's own database. Data is never sold, rented or shared with third parties. There are no ad networks, tracking pixels or sales.

4. Retention

  • Server settings: until the bot is removed from the server
  • User data (XP, balance, registration): until you request deletion
  • Temporary cooldown and similar technical records: minutes to a few days
  • Moderation logs: the period set by the server admin

5. AI

The in-server AI support assistant exists only to give you a fast answer to the question you ask. It processes your question at that moment and answers using FAQ data the server admin has entered.

Your messages are never used to train any AI model, are not collected as training data and are not exported. Conversation history is not kept for model training.

6. Your consent

When you first use the bot you are shown a consent panel. Without consent the bot will not run commands or process your messages. By giving consent you accept this policy.

To withdraw consent, use r!verisil or contact us via the support server below.

7. Your rights

To view, correct or delete the data we hold about you, use r!verisil or contact us. When you do:

  • We delete your data within 30 days
  • Deleted data is also removed from backups
  • Since no data was ever shared, there is nothing to recall elsewhere

8. Changes

If we update this policy we publish it on this page and bump the version number above. Significant changes are announced in the support server.

9. Contact

For any privacy question, request or complaint:

  • Support server: dsc.gg/risebunny

Note: This policy describes general principles for processing personal data. It is not legal advice. In case of a legal dispute, the data protection law of your own country applies.
